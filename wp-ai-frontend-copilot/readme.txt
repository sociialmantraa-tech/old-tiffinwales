== Description ==
WP AI Frontend Copilot allows you to modify and design your WordPress website frontend using conversational AI directly from your WordPress Admin Dashboard.

= Key Features =
* **Zero-Crash Architecture:** Never touches physical PHP or core theme files. All changes are stored securely in the database.
* **No File Re-uploading Required:** Change designs, animations, responsive rules, colors, and layout styles in real-time.
* **Interactive Live Preview:** Test your AI changes inside the dashboard with Desktop, Tablet, and Mobile device frames before applying.
* **1-Click Rollback & Revision History:** Automatic snapshots allow you to revert to any previous design with a single click.
* **Multi-AI Provider Support:** Works seamlessly with Google Gemini API (Fast & Free tier) and OpenAI (GPT-4o / GPT-4o-mini).

== Installation ==
1. Download the `wp-ai-frontend-copilot.zip` archive.
2. In your WordPress Admin Dashboard, navigate to **Plugins > Add New > Upload Plugin**.
3. Choose `wp-ai-frontend-copilot.zip` and click **Install Now**.
4. Click **Activate Plugin**.
5. Go to the new **AI Copilot** menu in your WordPress sidebar, paste your API key (Gemini or OpenAI), and start designing!
